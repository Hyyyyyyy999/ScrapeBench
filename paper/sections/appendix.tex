\subsection{Data Integrity Notes}
\label{app:integrity}
The first execution exposed three faults, all subsequently repaired and rerun. \emph{(i) Agent face-crop tier (T3).} The original crop implementation interpreted a per-side margin of $.35$ as a total width/height multiplier, producing undersized galleries and $25/27$ unusable cells. Correcting the crop extent restores the clean control (conditional identity $.376$, detection $81.7\%$) and completes $6\times3=18$ cells (Table~\ref{tab:repaired}). We retain T3 as a separate pilot rather than pooling it into the original 40-identity table. \emph{(ii) Stage C.} The original mixer drew clean images from other identities and the purification label did not execute the intended img2img-50 path. Same-identity mixing and true strength-$.5$ purification complete all 18 pilot cells; the low attack success and absence of matched endpoints limit causal interpretation. \emph{(iii) InstantID.} Batched prompt conditioning was inconsistent with the adapter embedding batch. Passing one prompt with an explicit images-per-prompt count fixes the mismatch; a $6$-identity $\times3$-method $\times4$-tier grid now completes all 72 cells at 30 denoising steps (Table~\ref{tab:instantid}). The append-only log preserves the failed and pre-protocol rows, while analysis selects the latest successful row per key.

\subsection{Reproducibility}
\label{sec:repro}
The complete harness (\texttt{scrapebench}) is released under an open license with: (i) the tier registry implementing the funnel as pure image functions with deterministic fallbacks; (ii) per-stage runners (\texttt{protection\_run}, \texttt{stage\_a}, \texttt{stage\_b}, \texttt{stage\_c}, \texttt{stage\_order}) writing append-only CSVs keyed by (stage, identity, defense, tier, attack) and resuming deterministically; (iii) the report generator producing retention tables against same-identity baselines, paired Wilcoxon tests with Holm correction, bootstrap CIs, and figures; (iv) a cost ledger emitted per cell. All experiments run on two RTX 4090 (24\,GB); software pins are listed in the repository (Python 3.10, torch 2.x CUDA, diffusers 0.31, transformers 4.44, peft 0.13, insightface 0.7). Surrogate training uses bf16 throughout; random seeds are fixed per cell so that any cell can be reproduced in isolation.

\subsection{Ethics Statement}
\label{sec:ethics}
This work evaluates \emph{defenses}, not attack tooling: the attack pipelines used are publicly released research artifacts (DreamBooth-LoRA~\cite{ruiz2022dreambooth}; IP-Adapter-FaceID~\cite{ye2023ipadapter}) executed with default settings on a public celebrity face corpus under its license, and no attempt is made to identify or de-anonymize the depicted individuals. Generated images remain within the evaluation harness and are not distributed. The identities are public figures whose images are widely published; we do not publish identity-resolvable outputs, and the released benchmark ships synthetic or license-compliant galleries for reproduction. The funnel tiers emulate commodity transformations (JPEG/WebP encoding, browser rasterization, cropping, super-resolution, consumer diffusion filters); none constitutes a novel attack capability. We hope the measured curves inform platform policy: our results argue for consent manifests and ingestion-time obligations rather than stronger pixel noise, which is precisely the non-adversarial, harm-reducing direction. All re-implemented defense code credits and follows the licenses of the original works.

Tables~\ref{tab:stageB}--\ref{tab:repaired} report the Stage-B fine-tuning comparison, the completed Stage-O ordering programs, the standard-reader stress grid, and the repaired pilots. The completed Stage-O composition study (108 cells, matched controls) found that no reordering or deepening of the funnel rescues a protection gap---every program's FSMG gap falls or its clean control collapses---which is why the primary analysis evaluates each preprocessing operation in isolation and reports composition only here.

\subsection{Protection Quality}
\label{app:quality}
The deployed perturbations respect the $\epsilon=16/255$ ball with PSNR against the source gallery in the high-$20$s\,dB range for every defense (FSMG, ASPL-lite, and the random control), consistent with the visibility budgets of the original works; the JPEG-aware variant operates at the same norm budget. Quality metrics per method are emitted by \texttt{protection\_run} into the released logs.
