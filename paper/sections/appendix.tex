\subsection{Reproducibility}
\label{sec:repro}
The complete harness (\texttt{scrapebench}) is released under an open license with: (i) the tier registry implementing T0--T6 as pure image functions with deterministic fallbacks; (ii) per-stage runners (\texttt{protection\_run}, \texttt{stage\_a}, \texttt{stage\_b}, \texttt{stage\_c}) writing append-only CSVs keyed by (stage, identity, defense, tier, attack) and resuming deterministically; (iii) the report generator producing collapse curves, retention tables, paired Wilcoxon tests with Holm correction, Cliff's $\delta$, and bootstrap CIs; (iv) a cost ledger emitted per cell. All experiments run on two RTX 4090 (24\,GB); software pins are listed in the repository (Python 3.10, torch 2.x CUDA, diffusers 0.31, transformers 4.44, peft 0.13, insightface 0.7). Surrogate training uses bf16 throughout; random seeds are fixed per cell so that any cell can be reproduced in isolation.

\subsection{Ethics Statement}
\label{sec:ethics}
This work evaluates \emph{defenses}, not attack tooling: the attack pipelines used are publicly released research artifacts (DreamBooth-LoRA~\cite{ruiz2022dreambooth}; IP-Adapter-FaceID~\cite{ye2023ipadapter}) executed with default settings on a public celebrity face corpus under its license, and no attempt is made to identify or de-anonymize the depicted individuals. Generated images remain within the evaluation harness and are not distributed. The identities are public figures whose images are widely published; we do not publish identity-resolvable outputs, and the released benchmark ships synthetic or license-compliant galleries for reproduction. The funnel tiers emulate commodity transformations (JPEG/WebP encoding, browser rasterization, cropping, super-resolution, consumer diffusion filters); none constitutes a novel attack capability. We hope the measured collapse curves inform platform policy: our results argue for consent manifests and ingestion-time obligations rather than stronger pixel noise, which is precisely the non-adversarial, harm-reducing direction. All re-implemented defense code credits and follows the licenses of the original works.
